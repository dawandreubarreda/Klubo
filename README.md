# Klubo

## 1. Nombre de la Empresa
**Klubo Gestión Deportiva**

## 2. Actividad Principal
Klubo es un sistema de gestión integral para clubes deportivos locales. Su objetivo es digitalizar y simplificar la administración de personas (jugadores, entrenadores, administradores), equipos, categorías y asistencia a entrenamientos. Está pensado para pequeños y medianos clubes que necesitan una herramienta accesible, segura y fácil de usar para organizar su día a día y sus temporadas.
